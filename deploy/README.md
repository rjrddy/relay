# Optional hosted demo configuration

No service or account has been created. Review the host and persistence policy before deployment.

Render supports free web services and free Postgres, but not free standalone background workers. This blueprint therefore runs the existing worker implementation in the web process with RELAY_EMBEDDED_WORKERS. Normal Compose keeps workers in separate processes. The Postgres database remains the durable authority; this embedding changes failure isolation, not the step commit protocol.

Free web instances can sleep. Processing stops while the web instance is asleep; it resumes when the process wakes and reclaims expired leases. Free Postgres has an expiry and storage limit. No hosted durability/availability or latency SLO is claimed. Do not describe this demo plan as production persistence.

The operator password and SDK token are generated by Render; retrieve them privately from the service environment. Secure cookies require HTTPS. OTLP export is optional and must point to an explicitly provisioned collector if enabled. Database migrations and synthetic seeding run at startup for this demo, so the runtime DB user needs migration privileges. A production deployment should split migration credentials from restricted runtime credentials.

Official references checked during implementation: [free plan](https://render.com/docs/free), [Blueprint specification](https://render.com/docs/blueprint-spec). These document provider policy, not performance measured by this repository.
