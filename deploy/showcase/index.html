03 / WHAT THE ENGINE GUARANTEES

SDK / console→Go API→Postgres↔Fenced workers
Route notes / inspect the failure boundary

One internal effect

The effect, step state, and successor transition commit in the same transaction. Epoch and expiry checks reject stale workers.

Visible failure

Retries have a budget. Exhausted work enters a dead-letter queue. Manual replay preserves completed prefix effects.

Precise boundaries

At-least-once execution. No exactly-once guarantee for arbitrary external HTTP, email, or payment effects.

An evidence gap, kept visible.

The hour run reconciled successfully, then exited with an error while exporting its complete event history. Complete SQL reconciliation and worker logs survive; only a prefix of the event stream is available. The paginated exporter fix passed a short run. The hour was not rerun.
